# Breast Cancer Data Analysis & Prediction

This project focuses on the analysis and prediction of breast cancer using machine learning techniques.

## Contents
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Model building and evaluation
- Research paper documenting methodology and results

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Google Colab

## Files Included
- `BREASTCANCER.ipynb` – Complete implementation
- `Research_Paper.pdf` – Detailed academic paper

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook
2. Upload the dataset 
3. Run cells sequentially
